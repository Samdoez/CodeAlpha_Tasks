# UrlCut - Express & PostgreSQL URL Shortener

A fast, reliable backend web service and server-side rendered application built with Node.js, Express, and PostgreSQL 

---

Features

Core Backend Functionality
URL Shortening Engine 
Dynamic Link Redirection
PostgreSQL Database Integration
Server-Side Rendering (SSR)

Data Integrity & Safety Features

Duplicate Prevention
URL Protocol Validation.
Favicon Handling

---
Tech Stack

Backend: Node.js, Express.js
Database: PostgreSQL (`pg` module)
Templating Engine:EJS (Embedded JavaScript)
Security & Utilities:** Node `crypto` module, `dotenv`
